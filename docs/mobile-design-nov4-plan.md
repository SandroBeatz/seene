## Решения владельца (2026-11-04)

Там, где дока или доски расходятся с этим списком, действует список.

| Вопрос | Решение |
| --- | --- |
| Ссылка на запись | Остаётся личная ссылка `/c/<token>`, а не `/<username>/b/<id>` из доки |
| «Просьба о переносе» | Заменяем на «Клиент перенёс запись» с кнопкой «Написать»: клиент переносит сам по ссылке |
| «Визит не подтверждён» | Текст «Клиент не подтвердил». Статус прочтения в WhatsApp не показываем: приложение его не видит |
| Автозавершение | Переключатель в настройках. Когда он включён, мастер выбирает способ оплаты по умолчанию. По умолчанию выключено |
| «Уведомления мне» на `AppMenuSettings` | Вместо трёх переключателей одна строка на новый экран настроек |
| Валюта | Всегда валюта мастера. В примерах по умолчанию доллар. Тарифы в USD |
| Чаевые | Убираем полностью: окно завершения и аналитика |
| Кнопка «Попробовать 14 дней бесплатно» | Пока убираем. До подключения покупок платный тариф показывает «Скоро» |
| «Сохраним, когда появится связь» | Без очереди: честный тост «Нет интернета» и «Повторить», текст меняем |

## Принято по умолчанию

- Обычное удаление идёт без диалога, только тост с «Отменить». Диалог остаётся для удаления аккаунта.
- Тип «Новое в Seene» откладываем: пока неоткуда публиковать новости.
- Пуши не блокируют остальное. Доступы Apple и Google понадобятся к этапу 12.
